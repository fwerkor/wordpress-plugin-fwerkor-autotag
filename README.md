# FWERKOR AutoTag

Controlled automatic tagging for WordPress.

Unlike title-splitting tag plugins, AutoTag uses explicit keyword-to-tag rules. It never turns full titles, categories, or arbitrary word fragments into tags.

## Features
- Explicit reusable keyword rules
- Preserves manual tags
- Tracks only tags it manages
- Maximum automatic tag count
- Bulk rebuild for published posts
- No external API and no telemetry
